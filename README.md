# Bot de Discord sobre Mudanças Climáticas

## Aqui está a ideia do meu projeto:

> Um bot de Discord, feito em Python, que ensina as pessoas sobre mudanças
> climáticas de forma simples e interativa, e depois testa se elas realmente
> entenderam o assunto.

## Qual problema ele ajuda a resolver?
Muita gente ainda não entende o que são as mudanças climáticas, por que elas
estão se intensificando e o que dá pra fazer a respeito. Informação clara e
acessível é o primeiro passo para mudar atitudes.

## Como o bot funciona?
1. Explica **o que são** as mudanças climáticas
2. Mostra **como elas ocorrem**
3. Mostra **como estão se intensificando**
4. Ensina **como podemos preveni-las**
5. Faz um **questionário final** para verificar se a pessoa aprendeu

## Tecnologias
- Python
- Biblioteca discord.py
